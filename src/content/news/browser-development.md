The current codebase includes a browser client built from the same game logic as the desktop game. Its documented features include tutorials, campaigns, custom games, map editing, browser-local saves, and online multiplayer.

The new online platform adds guest play, matchmaking, player profiles, match history, and verified rated-queue results. Browser play remains early access.

Browser work also covers threaded execution and renderer fallbacks. A development feature is not a guarantee that every device is qualified for a public release: release packages and their notes remain the place to check availability.

Follow the [game repository](https://github.com/Globulation2/glob2) for changes and [release downloads](https://github.com/Globulation2/glob2/releases) for published packages. Our [browser and multiplayer guide](/learn/browser-and-multiplayer/) explains the current save and connection behavior.
